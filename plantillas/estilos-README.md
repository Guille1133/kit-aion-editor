# Mis estilos

Cada estilo es la receta de un formato que repito. Se crea con `/aion-estilo` a partir de 2 o 3 reels de referencia.

| Estilo | Para qué formato | Referencias | Estado |
|---|---|---|---|

Estados:
- **borrador:** sin referencia medida. Se puede usar, avisando.
- **en-prueba:** medido sobre referencias y probado en un video. Falta mi OK.
- **aprobado:** aprobé un video final con este estilo. No se cambia sin preguntarme.
